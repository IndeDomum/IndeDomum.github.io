# indedomum.nl

Personal website of Tim Bolhoeve (about / CV), hosted on GitHub Pages at <https://indedomum.nl>.

## Structure

- `index.html`: the whole site (single page)
- `assets/css/personal.css`: styles
- `assets/js/personal.js`: mobile menu, footer year, hero hover effect
- `assets/img/`: portrait, favicon and social preview image
- `Logos/`: logos used in the header and footer
- `CNAME`: custom domain for GitHub Pages

## Updating

No build step. Edit the files, commit and push to `main`; GitHub Pages republishes within a minute or two.
