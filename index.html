01 Profile

About me

I’m a full-stack software engineer based in the Netherlands. I enjoy figuring out how systems and processes fit together, then turning that into software people can actually use.

At GDB Logistics, I work on integrations and internal web applications. A lot of that work is done with low-code platforms such as SnapLogic and OutSystems, alongside the usual engineering work around them.

Before that, I worked extensively with Python and Django to build high-code web applications.

I also use AI as part of my development process: to explore options, work through technical problems and turn an idea into a working solution more efficiently.

02 How I work

How I work

I prefer to understand the process first, make the solution clear, and keep improving it once it is in use.

01

Start with the process

Before building anything, I want to know how the work is done today and where it slows people down.

02

Keep it understandable

A useful solution should be straightforward for its users and manageable for the people who maintain it.

03

Improve as we go

The first release is a starting point. Feedback from daily use is what makes an application better.
